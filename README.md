# muginote studio — cafe design proposals

A neutral collection of ten unofficial cafe homepage concepts.

## Publishing

Repository: muginote-studio/muginote-studio.github.io
GitHub Pages: Deploy from a branch, main, / (root).
Public collection: https://muginote-studio.github.io/

Each cafe has its own directory: /uff/, /pocha/, /collage-co/, /noon/, /tori/, /yoca/, /aioi-coffee/, /cosajiichi/, /fourth-avenue/, /eggplant/.

Buildless static HTML, CSS and JavaScript. No dependencies.
These are independent proposals, not official store websites. Photographs are illustrative stock images. Information and image source links appear on each page. Replace imagery and obtain shop approval before official use.
