# 自主制作の抽象図案

非公式デザイン案のために制作したSVGです。実店舗・実商品・風景の再現や、店舗公式ロゴの複製ではありません。使用箇所で明記しています。各店舗の公開記事に記載の業態・商品や、確認済みの色を構成の手がかりとしています。

- sora-to-kaze-to.svg：風景を抽象化した色面
- bone-and-peace.svg：器と線の抽象構成
- curry-cafe-m.svg：円形の器を用いた幾何学構成
- hajimari-no-maho.svg：弁当箱を思わせる格子と色面
- imo-danshaku.svg：ジャケットポテトを手がかりにした抽象形
- minori.svg：ベーグルを手がかりにした円形の図案

文字ロゴや店名の由来、実商品の形・品質を示すものではありません。写真の転載許諾を代替する素材として扱わず、自主制作の表現として区別しています。
